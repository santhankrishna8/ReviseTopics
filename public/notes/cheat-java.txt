## static · final · this · super
- `static`: belongs to the class; no `this`; static blocks run once at class load.
- `final`: variable = assign once · method = no override · class = no subclass.
- `this(...)` calls another constructor; `super(...)` the parent's (first statement).
- Init order: parent static → child static → parent fields + ctor → child fields + ctor.

## Inheritance & Polymorphism
```java
abstract class Shape {
  abstract double area();
}
class Circle extends Shape {
  private final double r;
  Circle(double r) { this.r = r; }
  @Override double area() { return Math.PI * r * r; }
}
Shape s = new Circle(2);  // upcast
s.area();  // runtime dispatch
if (s instanceof Circle cc) { } // safe downcast
```
- One superclass (`extends`), many interfaces (`implements`). Fields and static methods are not polymorphic.

## Overriding vs Overloading
- **Override** (runtime): same signature in a subclass, covariant return, same or wider access, no broader checked exceptions; not `static`, `final`, `private`.
- **Overload** (compile time): same name, different parameters. Picks exact → widening → boxing → varargs.
```java
static void f(long v) { System.out.println("long"); }
static void f(Integer v) { System.out.println("Integer"); }
f(5);  // "long": widening beats boxing
```

## Exceptions

## Queue · Stack · PriorityQueue
```java
Queue<Integer> q = new ArrayDeque<>();
q.offer(1); q.peek(); q.poll();  // add, look, remove
Deque<Integer> stack = new ArrayDeque<>();
stack.push(1); stack.peek(); stack.pop(); // LIFO
var minHeap = new PriorityQueue<Integer>();
```

## Synchronization & Locks
```java
class Counter {
  private int count;
  synchronized void inc() { count++; }  // locks this
  private volatile boolean running = true; // visibility
}
var lock = new ReentrantLock();
lock.lock();
try { /* critical section */ } finally { lock.unlock(); }
var hits = new AtomicInteger();

```
- `count++` is not atomic even when `volatile`. **Deadlock** = threads waiting on each other's locks: lock in a fixed order or `tryLock` with a timeout.

## Virtual Threads (21+)
```java
try (var exec = Executors.newVirtualThreadPerTaskExecutor()) {
  for (int i = 0; i < 10_000; i++)
    exec.submit(() -> {
      Thread.sleep(Duration.ofMillis(10));
      return 1;
    });
}  // close() waits for all
Thread.ofVirtual().start(() -> System.out.println("v"));
```
- Cheap JVM-scheduled threads for **blocking I/O**; millions are fine. Do not pool them; no speed-up for CPU work. `ScopedValue` (25) replaces heavy `ThreadLocal`s.

```text
.java -> javac -> .class bytecode -> JVM
         (interpreter + JIT to native code)
JDK = JRE + tools · JRE = JVM + libraries
Heap       objects (Young: Eden+Survivors, Old)
Stack      one frame per call, per thread
Metaspace  class metadata (replaced PermGen)
```
- GC frees objects **unreachable from roots**. Collectors: Serial, Parallel, **G1** (default), ZGC (sub-ms pauses), Shenandoah.
- `OutOfMemoryError` = heap exhausted (leaks: static maps, caches, listeners). `StackOverflowError` = deep recursion.

## Interview One-Liners
- **JDK vs JRE vs JVM**: tools + runtime + engine.
- **== vs equals**: identity vs content.
- **String immutable**: pool, security, thread safety, cached hash.
- **final / finally / finalize**: no change · always runs · deprecated GC hook.
- **ArrayList vs LinkedList**: array (fast get) vs nodes (fast ends); ArrayList almost always.
- **HashMap / ConcurrentHashMap / Hashtable**: not thread-safe · thread-safe, fine-grained · legacy, fully locked.
- **Checked vs unchecked**: must handle vs programming errors.
- **map vs flatMap**: one-to-one vs flatten nested streams.
- **synchronized vs volatile**: lock + visibility vs visibility only.
- **Fail-fast vs fail-safe** iterators: throw `ConcurrentModificationException` vs iterate a snapshot.
