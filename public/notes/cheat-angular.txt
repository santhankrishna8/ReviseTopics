## Data Binding
```html
<p>{{ user.name }} · {{ total() | currency:'INR' }}</p>  <!-- interpolation -->
<img [src]="avatarUrl" [alt]="user.name">  <!-- property -->
```

## @if · @for · @switch
```html
@if (user(); as u) {
  <p>Welcome {{ u.name }}</p>
} @else if (loading()) {
  <p>Loading…</p>
} @else {
  <button (click)="login()">Log in</button>
}
@for (item of items(); track item.id; let i = $index) {
  <li>{{ i + 1 }}. {{ item.name }}</li>
} @empty {
  <li>No items</li>
}
@switch (status()) {
  @case ('active') { <span>Active</span> }
  @default { <span>Unknown</span> }
}
```
- `track` is required. Also `$first $last $even $odd $count`. No imports needed.

## @defer (lazy template blocks)
```html
@defer (on viewport; prefetch on idle) {
  <app-heavy-chart [data]="data()" />
} @placeholder (minimum 500ms) {
  <div class="skeleton"></div>
} @loading (after 100ms) {
  <p>Loading chart…</p>
} @error {
  <p>Failed to load</p>
}
```
- Triggers: `on idle` (default) · `viewport` · `interaction` · `hover` · `immediate` · `timer(2s)` · `when cond`.

```ts
@Directive({ selector: '[appUnless]' })
export class Unless {
```

## Component Communication
- **Parent → child**: `[input]`. **Child → parent**: `(output)`. **Both**: `model()` + `[(x)]`.
- **Parent calls child**: `viewChild(Child)` or `#ref` in the template.
- **Unrelated components**: a shared **service** holding signals or a `BehaviorSubject`.
- **Through the router**: params, query params, `data`, resolvers.

## Services & inject()
```ts
@Injectable({ providedIn: 'root' })  // app-wide singleton
export class CartService {
  private readonly http = inject(HttpClient);
  private readonly items = signal<{ price: number }[]>([]);
  readonly all = this.items.asReadonly();
  readonly total = computed(() => this.items().reduce((s, i) => s + i.price, 0));
  add(item: { price: number }) { this.items.update(l => [...l, item]); }
}
```
- `inject()` works in injection contexts: field initialisers, constructors, factories, guards, interceptors.

## Signals
```ts
const count = signal(0);  // writable
count.set(5);
count.update(c => c + 1);
const double = computed(() => count() * 2);  // derived, memoised
const todos = signal<string[]>([]);
todos.update(list => [...list, 'new']);  // new array, not push
```
- Read by calling: `count()`. Templates re-render when signals they read change. Signals compare with `===`.

## effect · linkedSignal · untracked
```ts
@Component({ selector: 'app-theme', template: '' })
export class Theme {
  readonly theme = signal('light');
  readonly options = signal(['S', 'M', 'L']);
  readonly selected = linkedSignal(() => this.options()[0]); // resets
  constructor() {
    effect(onCleanup => {
      const t = this.theme();  // tracked
      const n = untracked(() => this.options().length);
      const id = setTimeout(() => console.log(t, n), 100);
      onCleanup(() => clearTimeout(id));
    });
  }
}
```
- `effect` = side effects only (storage, logging). Never copy state with it: use `computed` / `linkedSignal`.

## resource · httpResource
```ts
@Component({
  selector: 'app-product-page',
  template: `
    @if (product.isLoading()) { <p>Loading…</p> }
    @else if (product.hasValue()) { <h2>{{ product.value().name }}</h2> }`,
})
export class ProductPage {
  readonly id = input.required<number>();
  readonly product = httpResource<{ name: string }>(() => `/api/products/${this.id()}`);
  readonly user = resource({
    params: () => ({ id: this.id() }),
    loader: ({ params, abortSignal }) =>
      fetch(`/api/users/${params.id}`, { signal: abortSignal }).then(r => r.json()),
  });
}
```
- Refetches when signals change; `value()`, `isLoading()`, `error()`, `reload()`.

## RxJS Interop
```ts
@Component({ selector: 'app-search', template: `{{ tick() }}` })
export class Search {
  readonly tick = toSignal(interval(1000), { initialValue: 0 });
  readonly query = signal('');
  readonly results = toSignal(toObservable(this.query).pipe(
    debounceTime(300), distinctUntilChanged(),
    switchMap(q => of(q ? [q] : []))));
  constructor() {
    interval(5000).pipe(takeUntilDestroyed()).subscribe();
  }
}
```

## Observables & Subjects
```ts
const events = new Subject<string>();  // no initial value
const state = new BehaviorSubject(0);  // current value: state.value
const history = new ReplaySubject<number>(2);// replays last 2
state.next(1);
state.subscribe(v => console.log(v));  // 1
```
- **Observable vs Promise**: lazy, many values, cancellable, operators vs eager, one value. HttpClient observables are cold.

## RxJS Operators
```ts
of(1, 2, 3).pipe(map(x => x * 10), filter(x => x > 10))
  .subscribe(console.log);  // 20, 30
from([1, 2, 3]).pipe(scan((a, x) => a + x, 0)); // 1, 3, 6
interval(1000).pipe(take(3));  // 0, 1, 2
forkJoin({ u: of('ann'), o: of([1]) });  // all complete -> one value
combineLatest([of('a'), of(1)]);  // latest of each
merge(of(1), of(2)); concat(of(1), of(2));
of('x').pipe(tap(v => console.log(v)), catchError(() => of('fallback')));
```

## Flattening Operators
```text
switchMap   cancel previous   search box, route -> GET
mergeMap    all in parallel   independent requests
concatMap   one at a time     ordered saves
exhaustMap  ignore while busy login button spam
shareReplay({ bufferSize: 1, refCount: true }) cache last value
debounceTime · throttleTime · distinctUntilChanged
```

## Unsubscribing
- `async` pipe, `toSignal`, `takeUntilDestroyed()`, `take(1)` or `unsubscribe()` in `ngOnDestroy`.
- HTTP calls complete on their own; `interval`, `fromEvent`, Subjects and `valueChanges` do **not**.

## Guards & Resolvers
```ts
export const authGuard: CanActivateFn = () => {
```

## Reactive Forms
```ts
@Component({
  selector: 'app-signup',
  imports: [ReactiveFormsModule],
  template: `
    <form [formGroup]="form" (ngSubmit)="save()">
      <input formControlName="email">
      <input type="password" formControlName="password">
      <button [disabled]="form.invalid">Save</button>
    </form>`,
})
export class Signup {
  private readonly fb = inject(FormBuilder).nonNullable;
  readonly form = this.fb.group({
    email: ['', [Validators.required, Validators.email]],
    password: ['', [Validators.required, Validators.minLength(8)]],
    phones: this.fb.array([this.fb.control('')]),
  });
  save() { console.log(this.form.getRawValue()); }  // typed
}
```

## Custom Validator & CVA
```ts
export const matchPasswords: ValidatorFn = g =>

@Component({
```

## Custom Pipe
```ts
@Pipe({ name: 'truncate' })  // pure by default
export class TruncatePipe implements PipeTransform {
  transform(value: string | null, max = 20, suffix = '…'): string {
    if (!value) return '';
    return value.length > max ? value.slice(0, max) + suffix : value;
  }
}
// {{ post.body | truncate:50 }}
```
- **Pure**: reruns only when the input reference changes. **Impure** (`pure: false`): every change detection.

## HttpClient
```ts
@Injectable({ providedIn: 'root' })
export class ProductApi {
  private readonly http = inject(HttpClient);
  list(page = 1) {
    const params = new HttpParams().set('page', page);
    return this.http.get<{ id: number }[]>('/api/products', { params })
      .pipe(retry(2), catchError(() => of([])));
  }
  create(p: { name: string }) { return this.http.post<{ id: number }>('/api/products', p); }
  remove(id: number) { return this.http.delete<void>(`/api/products/${id}`); }
}
```
- Observables are **cold**: nothing is sent until `subscribe`. `{ observe: 'response' }` gives status and headers.

## Interceptors
```ts
export const authInterceptor: HttpInterceptorFn = (req, next) => {
  const token = localStorage.getItem('token');
  const authReq = token
    ? req.clone({ setHeaders: { Authorization: `Bearer ${token}` } })
    : req;  // requests are immutable
  const router = inject(Router);
  return next(authReq).pipe(catchError((err: HttpErrorResponse) => {
    if (err.status === 401) router.navigate(['/login']);
    return throwError(() => err);
  }));
};
```

## Lifecycle Hooks (in order)
```text
constructor          DI only, inputs NOT set
ngOnChanges          an input changed (before init too)
ngOnInit             once: inputs ready, load data
ngDoCheck            every CD run (custom checks)
ngAfterContentInit   projected content ready
ngAfterViewInit      own view + children ready
ngOnDestroy          cleanup (or DestroyRef.onDestroy)
afterNextRender / afterEveryRender   DOM work, browser
```

## Change Detection
- **OnPush** (default in v22): check only on new input reference, own template event, signal it reads, `async` pipe emit, `markForCheck()`. **Eager** = old Default.
- **Zoneless** (default v21+): no zone.js; CD scheduled by signals, events, `markForCheck`. Old apps: `provideZoneChangeDetection()`.
- `markForCheck()` = mark dirty for later · `detectChanges()` = check now.
- Mutating an object input is not seen: pass a **new reference** or use signals.

## Performance
- Lazy routes (`loadComponent`, `loadChildren`) and `@defer`.
- `track` by id in `@for`; OnPush + signals; no heavy functions in templates (use `computed` or pure pipes).
- `NgOptimizedImage`: `<img ngSrc="hero.jpg" width="800" height="400" priority>`.
- Virtual scrolling (CDK) for long lists; bundle budgets in `angular.json`.

## Security
- Interpolation is escaped; `[innerHTML]`, `[href]`, `[src]` are sanitised automatically.
- `DomSanitizer.bypassSecurityTrust...` disables it: only for trusted content.
- HttpClient handles XSRF tokens for same-origin requests. Prefer HttpOnly cookies over `localStorage` for tokens.

## Versions
- **AngularJS** (1.x, 2010, EOL 2021) → **Angular 2** (2016, TypeScript rewrite). **9**: Ivy. **14**: typed forms, `inject()`. **15**: standalone stable.
- **16**: signals. **17**: `@if/@for/@defer`, esbuild + Vite. **18**: `@let`, zoneless (exp). **19**: standalone default, `linkedSignal`, `resource`.
- **20**: `*ngIf` deprecated, zoneless stable. **21**: zoneless + Vitest default. **22** (Jun 2026): OnPush default, Signal Forms, `httpResource` public, TS 6.0.

## Gotchas
- Missing from `imports` → "is not a known element" / "No pipe found".
- `@for` without a stable `track` id recreates DOM.
- Mutating arrays in signals or OnPush inputs → no update; use new references.
- Forgotten subscriptions leak; nested `subscribe` → use `switchMap`.
- `inject()` outside an injection context → NG0203.
- HTTP call without `subscribe` sends nothing.

## Interview One-Liners
- **Component vs directive**: directive with a template vs behaviour on an element.
- **Constructor vs ngOnInit**: DI vs init logic with inputs.
- **Pure vs impure pipe**: input reference change vs every CD.
- **Template-driven vs reactive forms**: template + ngModel vs code-first, typed, testable.
- **Subject vs BehaviorSubject**: no value vs current value replayed.
- **switchMap vs mergeMap**: cancel previous vs run all.
- **Signals vs RxJS**: sync state with auto-tracking vs async streams over time.
- **AOT**: templates compiled at build time (default).
- **providedIn: 'root'**: tree-shakable singleton.
- **Lazy loading**: `loadComponent` / `loadChildren` split code by route.
