# 01 | 14-Day Revision Plan | A day-by-day plan for Java, Angular, Spring Boot, Hibernate and SQL interviews: which cheat sheet to open, which cards to focus on, and what to practise out loud. Tick each day off with "Mark this sheet complete" when the whole plan is done, and rate yourself at the bottom. | Study plan

### How to Use This Plan

## The Daily Routine (about 3 hours)
> **Logic:** read, then recall, then practise. Reading alone feels productive but does not stick.
- **45 min: read** the day's cards in the cheat sheet. Say each definition **out loud** in your own words.
- **30 min: self-test.** Turn on **Self-test** (button at the top of a cheat sheet) so only the titles show; answer first, then reveal.
- **45 min: practise** coding or queries from the day's list. Write them by hand or in an editor **without looking**.
- **30 min: the full notes** for anything marked shaky (open the topic's detailed sheets in the sidebar).
- **10 min: rate yourself** at the bottom of each sheet (Shaky / OK / Solid) so you know what to revisit.
! Recall beats rereading. If you cannot say it out loud, you do not know it yet.

## Study Order & Priorities
> **Logic:** spend time where interviews spend time.
- **Highest weight:** Java core + collections, Spring Boot + REST, SQL queries, Hibernate (N+1, lazy loading, transactions).
- **Medium weight:** Angular (components, RxJS, forms, routing), Spring Security, concurrency.
- **Always asked:** "explain your project", scenario questions, one coding problem, one SQL query.
- Mark topics **must-know** in the Q&A sections: start with the starred questions in every detailed note.
- If you only have **7 days**, do Days 1, 2, 3, 5, 6, 8, 10, 11, 13 and 14.
! Depth on the common questions beats shallow coverage of everything.

### Week 1: Core Java, Collections, SQL

## Day 1: Java Basics & OOP
> **Open:** Java cheat sheet → Java Basics, OOP, Exceptions.
- **Cards:** JDK/JRE/JVM, `==` vs `equals`, String pool, immutability, `final`, `static`, abstract class vs interface, overloading vs overriding, `equals/hashCode` contract, checked vs unchecked.
- **Also:** Core Language Deep Dive (initialization order, Integer cache, `var`, text blocks).
- **Practise:** explain each term with a small example; **Java Coding Questions** → Strings (reverse, palindrome, anagram, first non-repeated).
! You should be able to explain String immutability in 30 seconds.

## Day 2: Collections & Generics
> **Open:** Java Collections cheat sheet, Java cheat sheet → Collections & Generics.
- **Cards:** HashMap internals (hashing, collisions, treeify, resize), ArrayList vs LinkedList, HashSet/TreeSet, Comparable vs Comparator, fail-fast, ConcurrentHashMap, complexity table, generics + wildcards + type erasure.
- **Practise:** **Java Coding Questions** → Collections & Streams (frequency map, sort map by value, LRU cache).
! HashMap internals is the single most asked Java question.

## Day 3: Java 8+ Functional, Streams & Exceptions
> **Open:** Java cheat sheet → Java 8+ Functional Programming; Gotchas & Edge Cases.
- **Cards:** lambdas, functional interfaces, method references, Stream API, `map` vs `flatMap`, Collectors, Optional, Date/Time, Stream & Optional pitfalls, Java 8/11/17/21 comparison.
- **Practise:** write 10 stream one-liners (filter, group by, second highest, joining, partition) without looking.
! Know what is lazy and what is a terminal operation.

## Day 4: Multithreading & JVM
> **Open:** Java cheat sheet → Multithreading & Concurrency, JVM & Memory, Concurrency Deep Dive, JVM Deep Dive.
- **Cards:** thread lifecycle, `synchronized`, `volatile`, deadlock, `wait` vs `sleep`, ExecutorService, CompletableFuture, atomics/locks, virtual threads, JMM happens-before, GC types, memory areas, OOM causes.
- **Practise:** odd/even printing with two threads; producer-consumer with `BlockingQueue`; describe a deadlock and how to prevent it.
! Be ready to explain volatile vs synchronized vs atomic.

## Day 5: Java Coding Practice
> **Open:** Java Coding Questions cheat sheet (use **Self-test**).
- **Do:** Arrays (second largest, rotate, two sum, Kadane, move zeros, binary search), Numbers (prime, Fibonacci, factorial, GCD), Strings (valid parentheses, longest substring), Linked list (reverse, cycle, middle).
- Say the **logic** before coding; state the time and space complexity.
- Redo the ones you could not finish in 10 minutes. Then do the **Java Output Questions** sheet with Self-test on: predict each result before revealing it.
! Interviewers grade your reasoning, not just the final code.

## Day 6: SQL Fundamentals
> **Open:** SQL cheat sheet → Basics, Keys, Querying, Joins, Subqueries & CTEs.
- **Cards:** DDL/DML/DQL, keys and constraints, `WHERE` vs `HAVING`, `GROUP BY`, all joins, `UNION` vs `UNION ALL`, `EXISTS` vs `IN`, CTE, set operations, DDL & DML syntax.
- **Practise:** draw the sample tables and write every join type from memory.
! WHERE filters rows, HAVING filters groups.

## Day 7: SQL Advanced & Query Practice
> **Open:** SQL cheat sheet → Window Functions, Indexes, Transactions, Design & Performance; **SQL Query Questions** cheat sheet.
- **Cards:** window functions, ROW_NUMBER/RANK/DENSE_RANK, LAG/LEAD, index types and leftmost-prefix, EXPLAIN, ACID, isolation levels, deadlocks, normalization, MVCC.
- **Practise:** Nth highest, top N per group, duplicates (find and delete), anti-join, running total, consecutive days, pivot.
! Say the technique ("DENSE_RANK with PARTITION BY") before typing the query.

### Week 2: Spring, Hibernate, Angular, Interview Rounds

## Day 8: Spring Core & Spring Boot
> **Open:** Spring Boot cheat sheet → Spring Core, Boot Basics, Configuration, Spring Internals.
- **Cards:** IoC/DI, bean scopes and lifecycle, `@Component` vs `@Bean`, auto-configuration, starters, profiles, `@ConfigurationProperties`, circular dependencies, AOP, MVC request lifecycle, filters vs interceptors.
- **Practise:** explain what happens from "run main" to "first request answered".
! Auto-configuration plus conditions is the Boot answer.

## Day 9: REST APIs, Validation, Errors & Testing
> **Open:** Spring Boot cheat sheet → REST APIs, Validation & Errors, Testing, API Quality, Production Features.
- **Cards:** controller annotations, `ResponseEntity`, status codes, Bean Validation, `@RestControllerAdvice`/ProblemDetail, DTOs/MapStruct, pagination, versioning, test slices, Mockito, Actuator, Flyway.
- **Also open:** the **JUnit & Mockito** cheat sheet, and the Spring Boot cards on Jackson, Redis caching, messaging and logging.
- **Practise:** design a CRUD API for orders including errors and pagination; write the controller test.
! Consistent error format and correct status codes impress interviewers.

## Day 10: Hibernate & JPA
> **Open:** Hibernate & JPA cheat sheet (all cards).
- **Cards:** entity lifecycle, persistence context, dirty checking, `persist` vs `merge`, relationships and `mappedBy`, cascade/orphanRemoval, lazy vs eager, **N+1**, `JOIN FETCH`/EntityGraph, caching, locking, `@Transactional` rules, batching.
- **Practise:** explain N+1 with an example and three fixes; explain `LazyInitializationException`.
! N+1, lazy loading and @Transactional appear in nearly every Spring/Hibernate interview.

## Day 11: Spring Security, JWT & Microservices
> **Open:** Spring Security cheat sheet; Spring Boot cheat sheet → Microservices, Spring Cloud.
- **Cards:** filter chain, authentication flow, `SecurityFilterChain`, JWT structure and validation, refresh tokens, OAuth2/OIDC, CSRF vs CORS, method security; monolith vs microservices, circuit breaker, saga, API gateway.
- **Practise:** draw the login-to-protected-call flow for a JWT API.
! 401 vs 403, and why CSRF can be disabled for stateless APIs.

## Day 12: Angular Fundamentals
> **Open:** Angular cheat sheet → Fundamentals, Templates & Directives, Component Communication, Services & DI, Lifecycle, Change Detection.
- **Cards:** components, standalone vs modules, data binding, directives, control flow, pipes, `@Input/@Output`, services and DI, lifecycle hooks, change detection and OnPush, `@defer`.
- **Practise:** parent-child communication example; explain the lifecycle order.
! ngOnChanges → ngOnInit → ngAfterViewInit → ngOnDestroy.

## Day 13: Angular Advanced: RxJS, Forms, Routing, HTTP
> **Open:** Angular cheat sheet → Signals & RxJS, Routing, Forms, HTTP, Advanced RxJS & State, Advanced Routing & Forms.
- **Cards:** signals vs observables, Subject types, `switchMap` vs `mergeMap` vs `concatMap` vs `exhaustMap`, preventing leaks, lazy loading, guards and resolvers, reactive forms and validators, interceptors, JWT flow, NgRx vs signals.
- **Practise:** write the typeahead search pipeline; build a reactive form with a custom validator.
! `switchMap` for search, `exhaustMap` for submit, `concatMap` for ordered.

## Day 14: Scenarios, Mock Interview & Weak Spots
> **Open:** Scenario & Project Answers cheat sheet; then every sheet's cards you rated **Shaky**.
- **Also:** work through two problems from the **Low-Level Design** sheet (parking lot, ATM) aloud.
- **Do:** write your two-minute **project explanation**, STAR stories, and answers for "slow API", "N+1", "production bug", "secure an API". Practise out loud or with a friend.
- Run a **mock interview**: 10 random questions from the Q&A sections with **Quiz mode** on, plus one coding problem and one SQL query under a timer.
- Re-rate all five topics; list three weak cards and re-read just those.
! The last day is for speaking practice, not new material.

### Before the Interview

## The Night Before & The Morning Of
> **Logic:** protect recall; do not cram new topics.
- Skim only the **Interview One-Liners** card at the end of each cheat sheet (Java, Spring Boot, Angular, SQL, Hibernate, Spring Security).
- Rehearse your project explanation, your 60-second introduction, and two questions to ask the interviewer.
- Test your setup (camera, mic, IDE or editor, internet) for online rounds; sleep properly.
- In the interview: **clarify the question, think aloud, state assumptions, give a simple answer first, then go deeper**, and say "I don't know, but I would find out by..." instead of guessing wildly.
! Calm, structured thinking out loud scores better than a memorised monologue.

## Tracking Your Progress
> **Logic:** use the app's own tracking.
- After each sheet, use **How well do you know it?** (Shaky / OK / Solid) at the bottom; revisit every Shaky sheet on Day 14.
- Use **Mark complete** on the detailed note sheets as you finish them.
- Use **Quick revise** on the detailed notes for a fast pass of definitions, tips and questions.
- Use **Must-know only** in the Q&A sections when time is short.
! Rate honestly: Shaky today means a quick win tomorrow.
