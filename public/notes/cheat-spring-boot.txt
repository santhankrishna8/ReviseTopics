## Create & Run
```bash
curl https://start.spring.io/starter.zip \
  -d dependencies=webmvc,data-jpa,validation -o app.zip
./mvnw spring-boot:run  # Gradle: ./gradlew bootRun
./mvnw clean package  # executable jar in target/
java -jar target/app.jar --server.port=9090 --spring.profiles.active=prod
./mvnw spring-boot:build-image  # Docker image, no Dockerfile
```

## Main Class
```java
@SpringBootApplication
public class CatalogApplication {
  public static void main(String[] args) {
    SpringApplication.run(CatalogApplication.class, args);
  }
}
```
- `@SpringBootApplication` = `@Configuration` + `@EnableAutoConfiguration` + `@ComponentScan` (this package and below: keep it in the **root** package).
- Auto-config: classes in `AutoConfiguration.imports` applied when `@Conditional`s pass. **Your beans win**. Debug with `--debug`.

## Stereotypes & Injection
```java
@Service  // also @Component @Repository @Controller
class ProductService {
  private final ProductRepository repo;
  ProductService(ProductRepository repo) {  // constructor injection:
    this.repo = repo;  // final, testable, no @Autowired
  }
  BigDecimal priceWithTax(long id) {
    return repo.findById(id).map(p -> p.price.multiply(new BigDecimal("1.18")))
               .orElseThrow();
  }
}
```
- Avoid field injection (`@Autowired private X x;`): hidden dependencies, hard to test.

## @Configuration & @Bean
```java
@Configuration
class AppConfig {
  @Bean Clock clock() { return Clock.systemUTC(); }  // third-party object as a bean
  @Bean @Primary Mapper defaultMapper() { return new Mapper("default"); }
  @Bean Mapper strictMapper() { return new Mapper("strict"); }
}
record Mapper(String mode) {}

@Component
class UsesMappers {
  UsesMappers(Mapper primary,  // the @Primary one
              @Qualifier("strictMapper") Mapper strict,// by bean name
              List<Mapper> all) { }  // every Mapper bean
}
```
- Resolution: by type → `@Qualifier` → `@Primary` → parameter name. 0 matches or 2+ matches fail at startup.

## Profiles & Property Order
- Activate: `spring.profiles.active=dev` (property, `--arg`, env `SPRING_PROFILES_ACTIVE`). `application-dev.yml` overrides `application.yml`.
- Later wins: jar defaults → profile files → external `./config/` → **env vars** → `-D` system props → **command-line args**.
- Env names: `SPRING_DATASOURCE_URL` → `spring.datasource.url`. Secrets: env vars, Vault, K8s Secrets, never Git.

## REST Controller
```java
@RestController
@RequestMapping("/products")
class ProductController {
  private final ProductCatalog catalog;
  ProductController(ProductCatalog catalog) { this.catalog = catalog; }

  @GetMapping  // ?category=x&page=0&size=20&sort=price,desc
  Page<ProductDto> list(@RequestParam(required = false) String category, Pageable pageable) {
    return catalog.search(category, pageable);
  }
  @GetMapping("/{id}")
  ResponseEntity<ProductDto> get(@PathVariable long id) {
    return catalog.find(id).map(ResponseEntity::ok).orElse(ResponseEntity.notFound().build());
  }
  @PostMapping
  ResponseEntity<ProductDto> create(@Valid @RequestBody CreateProduct body, UriComponentsBuilder uri) {
    ProductDto saved = catalog.create(body);
    return ResponseEntity.created(uri.path("/products/{id}").build(saved.id())).body(saved);
  }
  @DeleteMapping("/{id}") @ResponseStatus(HttpStatus.NO_CONTENT)
  void delete(@PathVariable long id) { catalog.delete(id); }
}
interface ProductCatalog {
  Page<ProductDto> search(String category, Pageable p);
  Optional<ProductDto> find(long id);
  ProductDto create(CreateProduct body);
  void delete(long id);
}
record ProductDto(long id, String name, BigDecimal price) {}
record CreateProduct(@NotBlank String name, @NotNull @Positive BigDecimal price) {}
```

## Request Binding
- `@PathVariable` URL part · `@RequestParam` query/form (`required`, `defaultValue`) · `@RequestBody` JSON · `@RequestHeader` · `@CookieValue` · `@ModelAttribute` · `MultipartFile` uploads.

- Return: object (200 JSON) · `ResponseEntity<T>` (status + headers) · `void` + `@ResponseStatus` · `ProblemDetail`.

## Validation

```java
record SignupRequest(
```

## Custom Constraint
```java
@Target({ ElementType.FIELD, ElementType.PARAMETER, ElementType.RECORD_COMPONENT })
@Retention(RetentionPolicy.RUNTIME)
@Constraint(validatedBy = SkuValidator.class)
@interface ValidSku {
  String message() default "must look like ABC-123";
  Class<?>[] groups() default {};
  Class<? extends Payload>[] payload() default {};
}
class SkuValidator implements ConstraintValidator<ValidSku, String> {
  public boolean isValid(String v, ConstraintValidatorContext ctx) {
    return v == null || v.matches("[A-Z]{3}-\\d{3}");
  }
}
```

## Error Handling (ProblemDetail)
```java
class ProductNotFoundException extends RuntimeException {
  ProductNotFoundException(long id) { super("Product " + id + " not found"); }
}
@RestControllerAdvice
class ApiErrors extends ResponseEntityExceptionHandler {
  @ExceptionHandler(ProductNotFoundException.class)
  ProblemDetail notFound(ProductNotFoundException ex) {
    ProblemDetail pd = ProblemDetail.forStatusAndDetail(HttpStatus.NOT_FOUND, ex.getMessage());
    pd.setTitle("Product not found");
    return pd;  // application/problem+json
  }
  @Override
  protected ResponseEntity<Object> handleMethodArgumentNotValid(MethodArgumentNotValidException ex,
      HttpHeaders headers, HttpStatusCode status, WebRequest request) {
    ProblemDetail pd = ex.getBody();
    pd.setProperty("errors", ex.getBindingResult().getFieldErrors().stream()
        .collect(Collectors.toMap(FieldError::getField, fe -> String.valueOf(fe.getDefaultMessage()), (a, b) -> a)));
    return handleExceptionInternal(ex, pd, headers, status, request);
  }
}
```
- Extend `ResponseEntityExceptionHandler` for built-in MVC errors: otherwise Boot's own handler (with `problemdetails.enabled`) wins. Filter/security errors never reach `@ControllerAdvice`.

## JPA Entity
```java
@Entity
@Table(name = "products")
class Product {
  @Id @GeneratedValue(strategy = GenerationType.IDENTITY) Long id;
  @Column(nullable = false) String name;
  @Column(precision = 10, scale = 2) BigDecimal price;
  @Enumerated(EnumType.STRING) Status status = Status.ACTIVE;  // never ORDINAL
  @ManyToOne(fetch = FetchType.LAZY) @JoinColumn(name = "category_id")
  Category category;
  @Version Long version;  // optimistic locking
  @Transient String computed;  // not stored
  protected Product() {}  // JPA needs it
  Product(String name, BigDecimal price) { this.name = name; this.price = price; }
  enum Status { ACTIVE, DISCONTINUED }
}
```

## Relationships
```java
@Entity
class Category {
  @Id @GeneratedValue Long id;
  String name;
  @OneToMany(mappedBy = "category", cascade = CascadeType.ALL, orphanRemoval = true)
  List<Product> products = new ArrayList<>();
  void add(Product p) { products.add(p); p.category = this; }  // sync both sides
}
```
- Owner side holds the FK (`@ManyToOne` + `@JoinColumn`); other side `mappedBy`. `@ManyToMany` + `@JoinTable`.
- Defaults: `@ManyToOne`/`@OneToOne` EAGER, collections LAZY → make all LAZY.
- States: transient → managed (dirty checking) → detached → removed.

## Repositories & Derived Queries

```java
interface ProductRepository extends JpaRepository<Product, Long> {
```

## @Transactional
```java
@Service
class CatalogAdmin {
  private final ProductRepository products;
  CatalogAdmin(ProductRepository products) { this.products = products; }
  @Transactional
  void reprice(long id, BigDecimal price) {
    products.findById(id).orElseThrow().price = price;  // dirty checking, no save()
  }
  @Transactional(readOnly = true)
  List<Product> all() { return products.findAll(); }
  @Transactional(propagation = Propagation.REQUIRES_NEW, rollbackFor = Exception.class)
  void audit(String msg) throws Exception { }
}
```
- Rolls back on **unchecked** exceptions only (unless `rollbackFor`). Proxy-based: **self-invocation** and `private` methods are ignored.
- Propagation: `REQUIRED` (default) · `REQUIRES_NEW` · `NESTED` · `SUPPORTS` · `MANDATORY` · `NEVER`.

## N+1 & Lazy Loading
- **N+1**: 1 query for parents + 1 per parent for children. Fix: `JOIN FETCH`, `@EntityGraph`, `hibernate.default_batch_fetch_size`, DTO projections.
- `LazyInitializationException`: lazy field touched after the transaction. Fetch inside it; set `open-in-view: false`.
- `ddl-auto`: `none` · `validate` · `update` · `create` · `create-drop`. Production: `validate` + Flyway/Liquibase.

## Security Filter Chain
```java
@Configuration
@EnableMethodSecurity
class SecurityConfig {
  @Bean
  SecurityFilterChain api(HttpSecurity http) throws Exception {
    return http
        .csrf(csrf -> csrf.disable())  // stateless token APIs only
        .sessionManagement(s -> s.sessionCreationPolicy(SessionCreationPolicy.STATELESS))
        .authorizeHttpRequests(a -> a
            .requestMatchers("/actuator/health/**", "/public/**").permitAll()
            .requestMatchers("/admin/**").hasRole("ADMIN")
            .anyRequest().authenticated())  // first match wins
        .httpBasic(Customizer.withDefaults())
        .build();
  }
}
```
- Request → `FilterChainProxy` → `SecurityFilterChain` filters → `DispatcherServlet`. 401 = not logged in, 403 = not allowed.

## Logging
```java
@Service
class PaymentService {
  private static final Logger log = LoggerFactory.getLogger(PaymentService.class);
  void pay(String orderId, BigDecimal amount) {
    MDC.put("orderId", orderId);  // on every line
    try {
      log.info("Charging {} for {}", amount, orderId);

    } finally { MDC.remove("orderId"); }

}
```

## RestClient
```java
record Stock(String sku, int quantity) {}
@Service
class InventoryGateway {
  private final RestClient http;
  InventoryGateway(RestClient.Builder builder) {
    this.http = builder.baseUrl("https://inventory.example.com").build();
  }
  @Retryable(maxRetries = 3, delay = 200, multiplier = 2)  // Spring 7 core retry
  Stock stock(String sku) {
    return http.get().uri("/stock/{sku}", sku).retrieve()
        .onStatus(HttpStatusCode::is4xxClientError, (rq, rs) -> {

        .body(Stock.class);
  }
}

```

## Feign & Circuit Breaker
```java
@FeignClient(name = "inventory-service", path = "/stock")  // + @EnableFeignClients
interface InventoryFeign {
  @GetMapping("/{sku}") Stock get(@PathVariable("sku") String sku);
}
@Service
class StockFacade {
  private final InventoryFeign inventory;
  StockFacade(InventoryFeign inventory) { this.inventory = inventory; }
  @CircuitBreaker(name = "inventory", fallbackMethod = "unknown")
  @Retry(name = "inventory")
  Stock stock(String sku) { return inventory.get(sku); }
  Stock unknown(String sku, Throwable t) { return new Stock(sku, 0); }
}
```
- States: **CLOSED** (calls pass) → **OPEN** (fail fast, fallback) → **HALF_OPEN** (trial calls) → CLOSED/OPEN.

```java
        .route("orders", r -> r.path("/api/orders/**")
            .filters(f -> f.stripPrefix(1).retry(3))
            .uri("lb://order-service"))  // via discovery + load balancer
        .build();
  }
}
```
- Gateway = single entry point: routing, auth, rate limiting (Redis token bucket → 429), CORS.

## Distributed Data
- **Database per service**. No 2PC across services: use a **Saga** (choreography with events, or an orchestrator) with **compensating** actions.
- **Transactional Outbox**: save the event in the same local transaction, relay it to Kafka. Consumers must be **idempotent**.

## AOP & Proxies
```java
@Aspect
@Component
class TimingAspect {
  @Around("execution(* com.acme..*Service.*(..))")
  Object time(ProceedingJoinPoint pjp) throws Throwable {
    long start = System.nanoTime();
    try { return pjp.proceed(); }
    finally { System.out.println(pjp.getSignature() + " " + (System.nanoTime() - start)); }
  }
}
```
- Advice: `@Before` `@After` `@AfterReturning` `@AfterThrowing` `@Around`. Proxies (CGLIB/JDK) intercept only **external calls to public methods** → why `@Transactional`/`@Cacheable`/`@Async` ignore self-calls.

## Docker & Kubernetes
- `./mvnw spring-boot:build-image` or a Dockerfile on a JRE image; `-XX:MaxRAMPercentage=75`.
- Graceful shutdown is default (3.4+). Probes: `/actuator/health/liveness`, `/readiness` (on by default in Boot 4).
- Config via ConfigMaps/Secrets → env vars. Scale stateless instances horizontally.

## Versions
- **2.x**: `javax.*`, Java 8+ (EOL). **3.0** (2022): Java 17, Spring 6, **`jakarta.*`**, Micrometer tracing, native images, `ProblemDetail`.
- **3.2**: virtual threads, `RestClient`, `JdbcClient`. **3.4**: structured logging, `@MockitoBean`, graceful shutdown default.
- **4.0** (Nov 2025): Spring 7, Jakarta EE 11, Jackson 3, modular starters, API versioning, HTTP service clients, `@Retryable` in core, `@MockBean` removed. **4.1.1** is current.

## Pitfalls
- Main class not in the root package → beans not scanned.
- `@Transactional`/`@Async`/`@Cacheable` on private or self-called methods → ignored.
- Mutable state in singletons → data leaks between requests.
- Catching an exception inside `@Transactional` without rethrowing → commits.
- Returning entities from APIs → lazy errors, JSON recursion: use DTOs.
- `ddl-auto=update` in production; HTTP clients without timeouts; secrets in Git.

## Interview One-Liners
- **Spring vs Spring Boot**: framework vs auto-config + starters + embedded server.
- **@Component vs @Bean**: scanned class vs factory method.
- **@Controller vs @RestController**: views vs JSON body.
- **Constructor injection**: final fields, explicit, testable.
- **@Primary vs @Qualifier**: default choice vs exact pick.
- **REQUIRED vs REQUIRES_NEW**: join vs new transaction.
- **save vs saveAndFlush**: deferred SQL vs immediate.
- **@Mock vs @MockitoBean**: plain mock vs replaces a Spring bean.
- **CSRF**: needed for cookie sessions, off for stateless JWT APIs.
- **Circuit breaker**: stop calling a failing service, fail fast, retry later.
